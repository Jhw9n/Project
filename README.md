# 🍽️ 오늘식

> 공공 영양 기준을 기반으로 건강한 식습관 형성을 지원하는 iOS 식단 관리 서비스

<br/>

## 📱 프로젝트 소개

오늘식은 사용자가 매일 식사를 기록하고,
공공 영양 기준을 바탕으로 자신의 식습관을
직관적으로 확인할 수 있도록 도와주는 서비스입니다.

단순한 칼로리 계산이 아닌

- 권장 칼로리 대비 섭취량
- 탄수화물 · 단백질 · 지방 비율
- 식습관 피드백
- 주간 변화 분석

을 통해 건강한 식습관 형성을 목표로 합니다.

<br/>

## ✨ 주요 기능

### Home

- 오늘 섭취 칼로리
- 권장 칼로리 대비 진행률
- 탄수화물 · 단백질 · 지방 현황
- 건강 피드백
- 최근 7일 칼로리 그래프

### Record

- 날짜별 식사 조회
- 아침 / 점심 / 저녁 / 간식 기록
- 음식 등록 및 수정
- 일별 영양 정보 확인

### Profile

- 사용자 정보 관리
- 권장 칼로리 계산
- 체중 변화 그래프
- 체중 기록 관리
